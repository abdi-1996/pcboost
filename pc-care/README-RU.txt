PC CARE STUDIO 1.0 — Windows 10/11 x64

ЗАПУСК
PC-Care-Studio-Setup.exe — установка в профиль пользователя, ярлыки и удаление через настройки Windows.
PC-Care-Studio.exe — готовая переносимая программа, открывается двойным щелчком. Все ресурсы интерфейса встроены. Используется встроенный в Windows .NET Framework 4.x. Python, SDK, сервер и компиляция на вашем ПК не нужны.

ОСНОВНЫЕ ФУНКЦИИ
• Тёмный интерфейс, боковое меню, карточки CPU/RAM/VRAM и свободного места, график последних 5 минут.
• Плавающая панель и значок в трее. Закрытие крестиком по умолчанию скрывает программу; для завершения используйте «Выход» в трее.
• Данные NVIDIA: VRAM, загрузка, температура GPU и версия драйвера через nvidia-smi из установленного драйвера. AMD/Intel VRAM в данной версии не поддерживается.
• Очистка .tmp/.temp в пользовательском Temp: файлы старше 7 дней, предварительный выбор, подтверждение, эксклюзивный дескриптор при удалении. Ссылки, занятые, свежие, изменившиеся, системные и readonly-файлы пропускаются. Удаление окончательное.
• Корзина очищается отдельно штатным диалогом Windows. Кеш браузера, реестр, модели и проекты не очищаются.
• Фоновая очистка по включаемому расписанию 15/30/60 минут. CPU <=40%, RAM <=85%, все NVIDIA GPU <=30%; неизвестные GPU-показатели блокируют автоочистку. Если включена защита ComfyUI, нужен доступный сервер с пустой очередью. Работает, пока приложение открыто или находится в трее.
• Сортировка файлов верхнего уровня Загрузок/Рабочего стола и их подпапок: фото, видео, документы, аудио, архивы. Только файлы старше суток. Папки и модели не перемещаются, совпадающие имена пропускаются. SHA-256 и журнал позволяют отменить перемещение неизменённых файлов.
• Поиск до 200 крупных файлов >=100 МБ, максимум 20 000 каталогов за обход. Ничего автоматически не удаляется.
• Список RAM-процессов. Закрытие выбранного приложения обычным запросом его окну после подтверждения; фоновые/системные процессы принудительно не завершаются.
• Выгрузка моделей ComfyUI через /free при пустой очереди. Это не полное обнуление VRAM: Windows и другие приложения продолжают использовать GPU. Следующая генерация заново загружает модели. Не отправляйте новые задания в момент выгрузки.
• WMI-сведения об оборудовании и Windows, состояние накопителей через Get-PhysicalDisk, список автозагрузки, поиск доступных обновлений через Windows Update. Некоторые сведения могут быть недоступны из-за прав, отключённой службы или особенностей диска.
• HealthStatus — оценка Windows, не полный SMART-тест. Температура CPU и ремонт файлов Windows не реализованы. Автоматического поиска последних драйверов NVIDIA нет: есть установленная версия и переход на официальный сайт.

ИИ И CHATGPT
1. Выберите «ChatGPT — вход через аккаунт», нажмите Continue with ChatGPT и завершите вход на официальном сайте OpenAI. Реализован официальный поток для локального open-source приложения: PKCE, state/nonce, проверка RSA-подписи и параметров ID token, обновление и отзыв сессии. Доступность зависит от вашего аккаунта и текущих условий OpenAI. Реальный вход и платные запросы на пользовательском аккаунте при сборке не выполнялись.
2. Либо выберите OpenAI API, введите собственный API-ключ. Ключ хранится только в памяти приложения. API имеет отдельные тарифы.
3. Нажмите «Загрузить доступные модели», выберите текстовую модель или введите её ID. API-каталог может включать модели, не поддерживающие текстовый Responses API: в таком случае выберите другую текстовую модель.
4. Напишите вопрос. Показанный отчёт добавляется только при включённой галочке. Перед отправкой запрашивается подтверждение. Вопрос и история последних 4 обменов отправляются в OpenAI; ранее приложенные отчёты остаются в истории до «Новый диалог». История хранится только в памяти.
5. «Остановить запрос» прекращает ожидание/чтение ответа. Уже использованные ресурсы сервера могут учитываться в лимитах.
6. ИИ даёт советы; не запускает команды и не удаляет файлы. Без подключения доступно копирование отчёта в обычный ChatGPT.

ДАННЫЕ
Настройки, журнал и OAuth-токены: %LOCALAPPDATA%\PC-Care-Studio. Токены ChatGPT защищены Windows DPAPI для текущего пользователя, не включаются в отчёты. «Выйти из ChatGPT» пытается отозвать сессию и удаляет локальную запись. Если отзыв недоступен, программа сообщит об этом; отключить доступ можно в настройках ChatGPT.
ИИ не получает содержимое ваших файлов автоматически. Журналы содержат локальные пути и не отправляются в ИИ. Обновления Windows и вход/запросы OpenAI используют интернет; основная диагностика и очистка работают локально.

ОГРАНИЧЕНИЯ
Очистка не повышает вычислительную мощность GPU. Оценка необходимости апгрейда основана на текущих измерениях, а не обещании точного ускорения. Полностью освободить занятую VRAM без освобождения ресурсов их владельцами нельзя. Нет чистки реестра, сброса GPU-драйвера или отключения защиты.
Программа не подписана коммерческим сертификатом. Исходный код доступен в отдельной ветке репозитория. Не отключайте защиту Windows ради запуска; при блокировке проверьте происхождение и хеш файла.

СБОРКА И ПРОВЕРКИ
GitHub Actions: компиляция на Windows, проверки защищённых/занятых/изменённых временных файлов, сортировки и отмены, открытие всех страниц интерфейса и сохранение снимков. Реальное оборудование NVIDIA, ваш ComfyUI и ваш OpenAI-аккаунт требуют проверки на вашем ПК.
Сборка из исходников: pc-care/src/Build.cmd. Установщик собирается отдельным шагом workflow.
